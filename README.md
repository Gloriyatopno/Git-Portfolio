## Git Workflow

The workflow followed in this project is:

1. Initialize the Git repository.
2. Create project files.
3. Stage changes using `git add`.
4. Save changes with `git commit`.
5. Create feature branches for new work.
6. Make changes and commit them on the feature branches.
7. Merge feature branches into the main branch.
8. Push the repository to GitHub.
9. Create Pull Requests.
10. Resolve merge conflicts when required.
11. Keep the repository updated with meaningful commits.
